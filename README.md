# Java Data Structures 04

Java 제네릭과 컬렉션 프레임워크를 학습하고 예제 코드로 정리한 저장소입니다.

제네릭의 기본 사용법부터 `List`, `Set`, `Map`, `Deque` 등 Java 컬렉션 자료구조의 특징과 사용 흐름을 예제 코드로 학습했습니다.

## 학습 목적

Java 백엔드 개발에서 자주 사용되는 자료구조와 컬렉션 사용 방식을 이해하기 위해 정리했습니다.

단순히 컬렉션 API 사용법만 익히는 것이 아니라, 각 자료구조가 어떤 특징을 가지고 있고 어떤 상황에서 적합한지 이해하는 데 중점을 두었습니다.

## 학습 내용

- 제네릭 기본 개념
- 제네릭 클래스와 제네릭 메서드
- 타입 안정성
- 배열 기반 자료구조
- 연결 구조 기반 자료구조
- `List` 사용
- `Set` 사용
- `Map` 사용
- `Deque` 사용
- 컬렉션 자료구조별 특징 비교
- [개념 정리 파일 보기](./src/docs)

## 학습 포인트

- 제네릭을 사용해 타입 안정성을 높이는 방법을 학습했습니다.
- 배열과 연결 구조를 비교하며 자료구조의 기본 동작 방식을 이해했습니다.
- `List`, `Set`, `Map`, `Deque`의 특징과 사용 목적을 구분했습니다.
- 데이터를 저장하고 조회하는 방식에 따라 적절한 컬렉션을 선택하는 기준을 학습했습니다.
- Java 컬렉션 프레임워크가 백엔드 개발에서 자주 사용되는 이유를 예제 코드로 확인했습니다.
